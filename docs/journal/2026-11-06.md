# 2026-11-06

### 12:00 · milestone · The animation engine exists and draws a list

A picture of a run is now a whole picture per step, with ids that stay the same, and one engine compares two pictures to find what appeared and what changed (NEW, CHANGED, and what it was before, in words as well as by look). One step forward moves what moved over a fraction of the Playback speed; with Animations off, a jump or going back, the step is a plain change. Text, the saved image and the "... and N more" note belong to the engine, and a plugin can add a kind of drawing through a new slot. Only the list ships so far, drawn by a test fixture that is not Data.

**Why it matters:** Data, the algorithm shapes and the git graph can now share one way to draw and animate, instead of each drawing its own.
