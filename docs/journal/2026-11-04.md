### 00:00 · pivot · Everything becomes a plugin

After seeing DeepSeek's harness, the person decided aidea should keep its philosophy (layers, Contract, Tutor) but open up: a small kernel and everything else a plugin on one versioned API (ADR 0008). A spec of 65 stories and 17 tickets followed.

**Why it matters:** aidea stops being a closed box and becomes a platform others can extend.
**Evidence:** `docs/adr/0008-a-small-kernel-and-everything-else-is-a-plugin.md` · `.scratch/plugin-system/spec.md`
**In their words:** "todo debe ser un plugin"

### 03:00 · milestone · The plugin system works end to end

While the person slept, all 17 tickets were built test-first: loader, Panel slot, quarantine with a scan, install after confirming each blocking finding, enable/disable/remove, versions and dependencies, guard rules, events, safe mode and an emergency screen, updates shown as a difference, settings forms with secrets kept out of files, live inspection plus a template and a skill so the Builder can write and propose a plugin, a read-only Tutor tool, and a test tool for plugin authors. ### 03:30 · surprise · Live checks found what tests did not

A plugin whose folder sat under a package.json without `"type":"module"` failed only in the real app; the host now writes its own. Also: the default secret store is in memory, because the core runs as a child process of Electron and cannot reach its secure store.

**Why it matters:** an honest gap is written down instead of hidden.
**Evidence:** commit `188921c` · `.scratch/plugin-system/issues/13-settings-data-and-secrets.md`
