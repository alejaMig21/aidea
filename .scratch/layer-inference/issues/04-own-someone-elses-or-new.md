# 04: A Project is the person's own, someone else's to study, or new

**What to build:** When a Project is opened for the first time aidea asks which it is: my own, someone else's that I want to study, or a new one. The answer is kept for the person outside the Project and can be changed. It decides how the Tutor works (ticket 05). A new empty folder is offered as new.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The question appears once per Project, not at every opening, and the answer survives a restart.
- [ ] The answer can be changed from the Project switcher.
- [ ] The Tutor's class start receives the answer.
- [ ] Page tests at 1920 and 1280 pixels pass.
