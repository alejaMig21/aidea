# 13: Select any text to learn about it

**What to build:** The person selects text anywhere (a builder reply, a Rationale, a line of code in the code box) and a small control offers "just define" (a brief explanation with no class) and "enter the Tutor" (a class on that text, which becomes the topic of a free class and is added to the Plan if it fits). It works in Class mode and in Direct mode, and never selects text of the person's own input boxes.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] Through the protocol: "just define" returns a brief explanation from the Tutor without opening a class or writing the graph; "enter the Tutor" opens a class whose topic is the selected text.
- [ ] The selected text is sent as data to the Tutor (never as instructions) and limited in size.
- [ ] Works in both modes.
- [ ] Verified with a headless browser: select text in the chat and in the code box, the control appears next to the selection and closes with Escape.
