# 01: Shared work and real-time cursors

**What to build:** Two people work on the same Project and see each other's cursors. It needs hand-editable graphs (one file per Node, built) and a relay server. What a person understands (the Learner graph) stays private.

**Blocked by:** None (can start immediately).

**Status:** needs-info: an idea; a spec first (a relay server, what stays private)

- [ ] A spec says the relay, the identity and what is shared.
- [ ] Two instances edit one Node without losing either edit.
- [ ] The Learner graph and Evidence are never shared.
