# 05: One Components layer for several languages, with the language in each Node's info

**What to build:** A Project with several languages shows one Components layer, as today. Each Node's info says its language. When the Project has more than one language, each box also carries a small language tag; with one language the boxes stay as they are. The legend explains the tag.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] The core gives each code Node its language (from the plugin that read it).
- [ ] The Node's info shows the language in plain words.
- [ ] A mixed fixture Project shows the tag on every box; a single-language one shows none.
- [ ] The legend of Components has a row for the tag and the legend check passes.
- [ ] A project of 40 modules or fewer in one language draws exactly as before.
