# 14: Select text to learn

**What to build:** The person selects any text (a builder reply, a Rationale, a line of code) and chooses "just define" for a brief explanation with no commitment, or "enter the Tutor" to start the teaching loop on that text. This works in both Class mode and Direct mode.
