# 13: Probe

**What to build:** When a Project is created, the Tutor runs a short Probe: a few questions limited to the concepts that Project's goal depends on, to find what the person already understands. The results go into the Learner graph so the first decisions are not asked from zero.

**Blocked by:** 12

**Status:** ready-for-agent

- [ ] Creating a Project starts a Probe whose questions relate to the Project's stated goal.
- [ ] The Probe is short and can be skipped.
- [ ] Answers are recorded in the Learner graph and change which questions the Tutor asks later.
