# 06: A performance lens: how time and memory grow

**What to build:** A Lens (an overlay of information on a layer, as in the glossary) over Components and Flow that answers how the time and memory of a function grow with the size of the data: run it at sizes n, 2n, 4n, draw the growth and name it (linear, quadratic). No estimates are promised before it is measured in the same adapters.
