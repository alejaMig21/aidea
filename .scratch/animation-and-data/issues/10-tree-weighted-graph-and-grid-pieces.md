# 10: Tree, weighted graph and grid pieces

**What to build:** The third delivery (spec decisions 2 and 5). Three pieces in the registry, drawn from the recorded pictures: a tree, a graph with weighted edges, and a grid. A stack, a queue and a heap are lists. Each writes itself as text. Python records them for the classic algorithms: sorting, walking a tree, a shortest path in a weighted graph, a path in a grid. Real functions of these algorithms are the examples and the tests.

**Blocked by:** animation-and-data 09.

- [ ] A path search on a grid shows the cells, the visited ones and the path.
