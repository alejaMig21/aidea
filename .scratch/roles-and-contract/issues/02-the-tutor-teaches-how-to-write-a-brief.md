# 02: The Tutor teaches how to write a Brief

**What to build:** A Tutor lesson on what a good request to a Builder has and why. The person writes the Brief in their own words first (the co-authoring pattern of tutor 08); the Tutor checks it against the five parts, says what is missing, and may offer a better version as a Proposal that the person accepts or not. The Tutor never sends it: it has no way to.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] A scripted class teaches the parts, receives a Brief the person wrote, and names what is missing.
- [ ] The better version arrives as a Proposal and changes nothing until accepted.
- [ ] The class uses predict, explain and check like any other, and records its Evidence.
- [ ] The Tutor has no tool that sends a Brief (tested).
